# 사용 기술
- Unity 6.3 / C# — 게임과 Android 빌드 개발
- URP — 렌더링 파이프라인
- Firebase Authentication — 익명 로그인, Google 계정 연동 및 자동 로그인
- Cloud Firestore — 유저의 재화, 장비·아이템 인벤토리, 캐릭터와 스테이지 진행도 저장. 장비 강화·구매 등에 트랜잭션 적용
- Addressables — 원격 카탈로그 확인과 콘텐츠 다운로드, 런타임 에셋 로딩
- Google Mobile Ads — 전면 광고 로드·노출, 광고 간격 및 광고 제거 구매 상태 반영
- Unity IAP — 광고 제거와 후원 인앱 상품 처리
- DOTween — 데미지 텍스트의 이동·확대·페이드 애니메이션
- ScriptableObject — 캐릭터, 적, 장비, 아이템, 무기 강화 데이터 정의
- 제네릭 오브젝트 풀링 — 적·투사체·이펙트 등을 재사용해 생성·삭제 부담 완화
